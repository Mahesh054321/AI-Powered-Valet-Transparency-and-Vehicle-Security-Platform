#  Install:
#      python -m venv .venv
#      .venv\Scripts\activate            (Windows)
#      pip install -r requirements.txt

#  NOTE ON OPENCV:
#  We pin `opencv-python-headless` rather than `opencv-python`. It is the same
#  OpenCV build without the GUI/windowing layer (no cv2.imshow), which is what a
#  server needs: fewer system dependencies and no libGL problems on Linux/CI.
#  If you want to view windows while experimenting, swap in `opencv-python`.
